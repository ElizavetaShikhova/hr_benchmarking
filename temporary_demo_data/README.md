# Временные демоданные

> [!IMPORTANT]
> **Удалить весь каталог `temporary_demo_data/` после перехода на импорт CSV.**

Каталог содержит генератор вымышленных кадровых данных и проверки этого набора. Он нужен для локальной проверки текучести до появления загрузки CSV заказчиком.

## Загрузка

Из корня проекта примените миграции и запустите генератор.

```bash
python -m alembic upgrade head
python -m temporary_demo_data.seed
```

Генератор заполняет пустую HR-базу. Если в ней уже есть кадровые данные, загрузка пропускается.

На демоданных в новой базе запрос `GET /api/v1/metrics/turnover?enterprise_id=1&period=2026-09-01` возвращает для «Севера» текучесть `33,3333%` при плане `20%`.

## Проверка демоданных

На отдельной пустой тестовой базе примените миграции и выполните `python -m unittest temporary_demo_data.test_seed -v` перед загрузкой набора. Тест проверяет первую и повторную загрузку и откатывает изменения.

После появления импорта CSV замените подготовку данных для интеграционных тестов на загрузку эквивалентного контрольного набора и удалите каталог вместе со ссылками на него из корневого README.
